# CSM Implementation Plan — Continuous Symmetry Measures (symgroup reimplementation)

Status legend: `OPEN` `IN PROGRESS` `DONE` `BLOCKED` `DECIDE` (needs a maintainer decision; use the
recommended default and flag it in the PR). Update statuses **in place** as tasks land; do not
append new sections. Line references below drift — grep before trusting one.

This file is the brief for AI agents implementing a new **`csm`** module in cosmochlore. It is
self-contained: it specifies the measure, the algorithm, the module layout, the phases, the tests
and the known defects of the code being reimplemented. It implements `PLAN.md` Part II items
**9** (Zabrodsky–Avnir CSM) and **10** (continuous chirality measure). When a phase ships, update
those two items' status in `PLAN.md` in place.

---

## 0 · Ground rules for agents

1. **CSM is not CSoM.** cosmochlore already has `csom` (Continuous Symmetry *Operation* Measure,
   Sørensen et al. 2024). That is a different measure: it scores every symmetry operation
   independently, each with its own Hungarian atom matching, and averages the per-operation
   deviations. The CSM implemented here (Zabrodsky–Avnir, as in `symgroup`/`cosymlib`) is the
   normalised squared distance to the **nearest structure that has the symmetry**. That requires
   **one consistent permutation representation of the whole group**. Consequences:
   - `csm` is a **new module and a new subcommand**. Never change `csom`'s definition, defaults or
     numbers. `csom`, `cshm` and `odis` output must stay byte-identical after every phase — check it
     the same way `PLAN.md` D8/D9 did.
   - Do not call the CSM a "deviation", and do not present CSM and CSoM values as comparable.
   - Code *may* be shared (Hungarian solver, label grouping, seeding, geometry helpers, writers),
     but move shared helpers to a neutral module rather than importing `csom` internals into `csm`.
2. One phase (or one sub-task) per branch/PR. CI gates apply: `cargo test --locked`,
   `cargo clippy --all-targets -- -D warnings`, `cargo fmt --check`.
3. No new dependencies without a reason in the PR. `nalgebra`, `argmin`, `thiserror`, `clap` and
   `itertools` are already available. `rayon` is planned anyway (`PLAN.md` C8) but is optional
   here.
4. The program must never silently produce a number when something went wrong (README promise).
   Every failure path returns a `CsmError`. No `unwrap`/`expect` on data-dependent paths.
5. Performance tests must not assert wall-clock time (`PLAN.md` E3). Assert search-node counts
   instead.
6. Licences: `symgroup` is MIT (© 2018 David Casanova & Abel Carreras), so reimplementing it is
   fine with attribution in the README Licence section. The Tuvi-Arad/Avnir `csm` program
   (`github.com/continuous-symmetry-measure/csm`) is **GPL-2.0**: read it for ideas only and
   **do not copy code from it** (cosmochlore is GPL-3.0-only).

## 2 · The measure (normative specification)

### 2.1 Definitions

- Structure: N atoms with positions `x_k` and labels. Centroid `x̄` (unweighted, **all** atoms
  including the central atom). Centred coordinates `q_k = x_k − x̄`. Norm `A = Σ_k |q_k|²`
  (error if A ≈ 0).
- A cyclic group G of order **h**, generated by g(v) with unit axis v. Its elements are
  g_l(v) = g(v)^l for l = 0 … h−1, acting as:

  ```math
  g_l(v)\,x = \cos\theta_l\,x + \sin\theta_l\,(v\times x) + (\varepsilon_l-\cos\theta_l)\,(v\cdot x)\,v
  ```

  This is a counter-clockwise rotation by θ_l about v, followed by the reflection through the plane
  ⟂ v when ε_l = −1.

| Group label | h | θ_l | ε_l | Notes |
|---|---|---|---|---|
| `E`, `C1` | 1 | — | — | CSM ≡ 0 |
| `Cn` (n ≥ 2) | n | 2πl/n | +1 | |
| `Sn`, n even | n | 2πl/n | (−1)^l | `S2` ≡ `Ci` |
| `Sn`, n odd | **2n** | 2πl/n | (−1)^l | `S1` ≡ `Cs`. S_n with n odd generates the C_nh-type cyclic group of order 2n (see §3, defect D2) |
| `Ci` | 2 | π | −1 | inversion |
| `Cs` | 2 | 2π | −1 | reflection |

- A **valid permutation** P of the atoms satisfies all of the following:
  1. **P^h = identity**, i.e. every cycle length divides h.
  2. P maps every atom to an atom of the same label class (element symbol via
     `strip_label`; all atoms form one class with `--ignore`).
  3. The central atom (if any) is a fixed point.
  4. Optionally (Phase 5) P preserves the bond graph.

  Fixed points and cycles shorter than h are valid. Such atoms collapse onto the symmetry element
  in the nearest structure, which is legitimate in the CSM definition.

### 2.2 Measure, nearest structure, and why validity matters

For a valid P and an axis v, the nearest G-symmetric structure is the **folded/unfolded average**

```math
\hat p_k = \frac{1}{h}\sum_{l=0}^{h-1} g_l(v)\, q_{P^l(k)}
```

and the measure is

```math
\mathrm{CSM}(P,v) = 100\,\frac{\sum_k |q_k-\hat p_k|^2}{A}
               = 100\left(1-\frac{A+O(P,v)}{h\,A}\right),\qquad
O(P,v)=\sum_{l=1}^{h-1}\sum_k q_k\cdot g_l(v)\,q_{P^l(k)} .
```

**CSM = min over valid P and unit v.** The two expressions are equal only because the operator
(Tq)_k = g q_{P(k)} satisfies T^h = I when P^h = id, so (1/h)Σ T^l is an orthogonal projector.
For an invalid P the right-hand expression is **not** a distance to any symmetric structure and
can under-report the measure. This is why the search must be restricted to valid P (defect D1).

Normalisation matches symgroup: for Ci/Cs, `50(1 − s/A)`; for C_n/S_n with h = n,
`100(1 − (1 + s/A)/n)`. Here s = O. Clamp the final value to [0, 100] against round-off,
as `cshm` does.

### 2.3 Orientation for a fixed permutation (closed form)

O is a quadratic-plus-linear function of v:

```math
O(P,v) = c + v^{\mathsf T} M v + b\cdot v
```

```math
c=\sum_{l=1}^{h-1}\cos\theta_l\sum_k q_k\cdot q_{P^l(k)},\qquad
M=\sum_{l=1}^{h-1}(\varepsilon_l-\cos\theta_l)\,\mathrm{sym}\Big(\sum_k q_k\,q_{P^l(k)}^{\mathsf T}\Big),\qquad
b=\sum_{l=1}^{h-1}\sin\theta_l\sum_k q_{P^l(k)}\times q_k
```

where sym(X) = (X + Xᵀ)/2. Maximising vᵀMv + b·v on the unit sphere is a **trust-region
subproblem**, which is solvable to global optimality:

1. Eigen-decompose M = Σ μ_i e_i e_iᵀ with μ_1 ≥ μ_2 ≥ μ_3, and set β_i = e_i·b.
2. The global maximiser satisfies (M − λI)v = −b/2 with **λ ≥ μ_1**, so
   v(λ) = Σ_i β_i / (2(λ − μ_i)) · e_i.
3. If |β_1| > tol: λ* is the unique root on (μ_1, ∞) of the secular equation
   Σ_i β_i² / (4(λ − μ_i)²) = 1. The root is bracketed by
   [μ_1 + |β_1|/2, μ_1 + |b|/2]. Use bisection or Brent; Newton on the reciprocal form
   (Moré–Sorensen) is optional. Convergence is guaranteed.
4. **Hard case** |β_1| ≤ tol (e.g. C2, where all sin θ_l = 0 and so b = 0):
   - If Σ_{i: μ_i<μ_1} β_i² / (4(μ_1 − μ_i)²) ≤ 1, then λ* = μ_1 and
     v = Σ_{μ_i<μ_1} β_i/(2(μ_1−μ_i)) e_i + τ e_1, with τ chosen to make |v| = 1.
     Either sign of τ works; pick a deterministic one.
   - Otherwise fall back to step 3 restricted to the non-degenerate eigenvalues.
   - Treat a degenerate μ_1 = μ_2 the same way.
5. Optimal value: `O* = c + λ* + (b·v*)/2`, because vᵀMv = λ − b·v/2 at a stationary point.

Special cases fall out with no extra code paths:
- C2: b = 0, so v is the top eigenvector of M.
- Cs: v is the bottom eigenvector of Σ sym(q pᵀ).
- Ci: M = 0 and b = 0, so O = c.
- M ≈ 0: v = b/|b| and O = c + |b|.

**Sign convention test (mandatory).** Build an exactly C_n-symmetric structure about a random
axis u with a known n-cycle P, such that g(u) q_{P(k)} = q_k. The solver must return
v = **+u** and O = (h−1)A for P, and v = **−u** for P⁻¹. Do the same for S_4 and S_3.

### 2.4 Search-space facts used by the algorithm

- **Cycle independence.** O is a sum over cycles of P. Each cycle's contribution (to c, M and b)
  depends only on that cycle, so cycles are natural branch-and-bound blocks.
- **Inverse symmetry.** O(P⁻¹, −v) = O(P, v), because g_l(−v) = g_{h−l}(v) for both C_n and S_n
  (h is even for S_n). Enumerate only one of P and P⁻¹. Canonical rule: in the first cycle of
  length ≥ 3 (cycles ordered by their smallest atom), the second element must be smaller than the
  last. Involutions are self-inverse.
- **Count of candidate permutations** in a label class of size m:
  a_h(0) = 1, a_h(m) = Σ_{d | h, d ≤ m} (m−1)!/(m−d)! · a_h(m−d).
  The total is the product over classes (central atom excluded). Examples:

  | m | m! | h=2 | h=3 | h=4 | h=5 | h=6 | h=8 |
  |---|---|---|---|---|---|---|---|
  | 6 | 720 | 76 | 81 | 256 | 145 | 396 | 256 |
  | 9 | 362 880 | 2 620 | 5 769 | 33 616 | 3 025 | 91 548 | 78 976 |
  | 12 | 479 001 600 | 140 152 | 776 601 | 9 893 632 | 4 809 025 | 43 575 192 | 49 810 432 |

  Before branch-and-bound pruning, symgroup walks m! leaves for every group. Labels matter a lot.
  For `tests/ideal_benzene.xyz` run with `-n` (no central atom), C6 has 396² = 156 816
  candidates with labels, versus 43 575 192 with `--ignore`.
- **Subgroup monotonicity.** If H ⊂ G then CSM(H) ≤ CSM(G). Used for tests and for skipping
  groups in the chirality measure.

## 3 · Known symgroup defects and the improvements to make

Fortran references are at commit `7c75587`. Each row is something `csm` must do differently
(and document in the README).

| # | symgroup behaviour | Effect | cosmochlore `csm` |
|---|---|---|---|
| D1 | No P^h = id check for n ≥ 5. Only C3/C4/S3/S4 have cycle checks (`symgrouplib.F` ~696–721) | For n ≥ 5 any permutation is scored, including ones that represent no symmetric structure, so the measure can be under-reported. It also walks all m! leaves | Enumerate valid permutations only (§2.1) |
| D2 | Odd S_n uses only n−1 operations (`noper = oeix−1`, ~323, 385–387). S3 accepts P^6 = id but scores only S3¹ and S3² (~701) | Incomplete group, so the value is not the S_n measure | h = 2n for odd n (§2.1 table) |
| D3 | S4 accepts 8-cycles (P^8 = id, ~713–714) | Invalid permutations | P^h = id |
| D4 | The C4 2-cycle exclusion (~712) is dead code (it sits inside `P⁴(k) ≠ k`) | None, but misleading | n/a |
| D5 | Axis optimisation: 4-D Newton from 3 eigenvector starts, at most 100 steps × 2 halvings, silently returns −10⁶ on failure (`operations.F` 125–211) | Possible missed global optimum or a silent bad value | Global trust-region solve (§2.3) |
| D6 | Jacobi non-convergence only prints a warning (`jacobi.F`) | Silent bad value | nalgebra `SymmetricEigen` or closed form, with error propagation |
| D7 | Reference frame divides by `vmax(3)` (~946) | NaN when the optimal axis lies in the xy-plane, e.g. an in-plane C2 of a planar molecule | Robust frame: e1 = v, e2 = normalise(v × a) with a the coordinate axis least aligned with v, e3 = e1 × e2 |
| D8 | Connectivity pruning compares components of the top eigenvector of the adjacency matrix with tolerance 1e-6 (~458, 566–583, 660–663) | Wrong pruning when the top eigenvalue is degenerate (disconnected graphs); fragile in general | Exact graph constraints: Weisfeiler–Lehman colour refinement plus incremental edge-preservation check (Phase 5) |
| D9 | Radius table has zeros for noble gases and most lanthanides; unknown labels `stop` the process (`radius.F`, `connectivity.F:62`) | Lanthanide complexes (a core use case here) get no bonds | `data::elements::covalent_radius`, errors instead of `stop` |
| D10 | `multi` bookkeeping is capped at 15 with ad-hoc insertion and duplicates ±v (P vs P⁻¹) (~805–820) | Duplicate axes in the "N best" list | Top-k with distinct axes, deduplicated by the inverse symmetry |
| D11 | Inversion search forbids more than one fixed point, and any fixed point when the ligand count is even (~669–681) | Excludes valid (degenerate) permutations; rarely changes results | Allow all valid P; branch-and-bound prunes them |
| D12 | Fortran `stop` on bad input kills the host process; labels limited to 2 characters | Crashes; label truncation | `CsmError`; labels via `strip_label` |
| D13 | Centre: `symgroupy` always fixes the centre at the centroid when none is given, but the cosymlib docstring says "optimised" | Correct behaviour (the centroid *is* the optimal translation), misleading docs | Centroid by default, documented as optimal (§4.4) |
| D14 | Permutation search is a plain depth-first walk over positions; no bound | m! work | Cycle-wise branch-and-bound with an incumbent (Phase 2) |

**Parity policy.** Match symgroup to `1e-5` absolute (CSM scale 0–100) wherever symgroup's
returned permutation is valid and its Newton step converged. Where values differ, the PR must:
1. evaluate symgroup's returned permutation with our evaluator;
2. show it is invalid (D1–D3) or that our axis gives a strictly larger overlap (D5);
3. list the case in the README "Differences from symgroup" note.

## 4 · Architecture

### 4.1 Module layout (new)

```
src/csm/
  mod.rs          csm_main, calc_csm (driver; mirrors csom/mod.rs style)
  types.rs        CsmGroup, CsmSettings, CsmResult, CsmAxisResult, CsmError
  group.rs        group label parsing; per-group h, θ_l, ε_l tables; divisors of h; subgroup facts
  orientation.rs  (c, M, b) accumulation and the trust-region solver of §2.3
  cycles.rs       label classes, cycle enumeration, canonical form, candidate counting
  search.rs       exact branch-and-bound over cycles (Phase 2)
  approx.rs       alternating heuristic (Phase 6)
  nearest.rs      folded/unfolded nearest structure, self-consistency check
  connectivity.rs bond graph, WL refinement, edge checks (Phase 5)
  chirality.rs    continuous chirality measure (Phase 4)
  tests.rs        #[cfg(test)]
```

### 4.2 Types (described, not prescribed)

- **`CsmGroup`**: enum E | Ci | Cs | Cn(n) | Sn(n). Parsed from Schoenflies text: `E`, `C1`, `Ci`,
  `Cs`, `C<n>` (n ≥ 2), `S<n>` (n ≥ 1; `S1` → Cs, `S2` → Ci). Case-sensitive like `csom`.
  It exposes order h and per-operation (cos θ_l, sin θ_l, ε_l − cos θ_l) for l = 1 … h−1.
- **`CsmSettings`**: multi (k), ignore_labels, connectivity (`Option<factor>`),
  `fixed_permutation` (`Option<Vec<usize>>`), mode (Auto/Exact/Approx), exact_limit (candidate
  count above which Auto switches to approx), approx seeds/iterations. One `Default` impl is the
  single source of the CLI defaults, as `csom::types::OptimiserSettings` does (`PLAN.md` B10).
- **`CsmResult`** (per group):
  - group, csm, axis (unit vector, original frame), permutation (0-based internally, 1-based
    when printed);
  - nearest structure (original frame: un-centred and un-scaled);
  - reference frame (3 orthonormal axes);
  - `multi: Vec<(csm, axis)>`;
  - `exact: bool` (false when the approximate path produced the value);
  - search statistics (candidates counted, nodes visited).
- **`CsmError`** (`thiserror`): UnknownGroup, ZeroNorm, InvalidPermutation (for `--perm`:
  wrong length, not a bijection, crosses label classes, moves the centre, P^h ≠ id),
  SearchTooLarge (Exact forced above a hard cap), SolverFailed (must never fire; never silent).
  Add `Csm(#[from] CsmError)` to `error::Error`.

### 4.4 Centring and the central atom

- **Default translation: centroid of all atoms**, including the central atom. It is the optimal
  translation for this measure: the nearest symmetric structure shares the problem's centroid. This
  is also what `symgroupy` does by default.
- The **central atom** (cosmochlore convention: first atom unless `-n/--nc`; `-c POS` selects
  another) is **pinned as a fixed point** of every permutation. It is *not* used as the origin.
- `DECIDE` D-C: offer `-m manual -u X Y Z` (symgroup's `center`/CENTERFIX: a constrained measure
  with the symmetry element through a given point). Offer `-m first` (element through the
  central atom) only if the maintainer wants it; document that it is not the standard CSM.

### Phase 1 — Group model and orientation solver (pure math)

- `OPEN` **P1.2** `orientation.rs`: (c, M, b) accumulation for a given permutation, and the

- `OPEN` **P1.3** Tests:

### Phase 2 — Exact search for E, Ci, Cs, C_n, S_n

- `OPEN` **P2.1** `cycles.rs`: label classes (centre pinned; `--ignore` merges classes), and the
  candidate count a_h (§2.4, saturating arithmetic). Generate cycles canonically: take the
  smallest unassigned atom k, choose a cycle length d | h with d ≤ the remaining class size, then
  choose an ordered (d−1)-tuple of other unassigned atoms in k's class. Apply the P vs P⁻¹
  canonical rule. Every valid permutation must be generated exactly once, up to inversion.
- `OPEN` **P2.2** `search.rs`: branch-and-bound over cycles.
  - Precompute the pair blocks q_k q_jᵀ (like `cshm` `SearchTables::hi`). Each cycle's
    contribution to (c, M, b) is a sum of these blocks weighted by the per-operation
    coefficients.
  - Keep (c, M, b) for the assigned cycles incrementally (add on descend, subtract on backtrack,
    as `cshm` does with `h_partial`).
  - **Bound**: max_v O_assigned(v) (solver of P1.2) plus
    Σ_{k unassigned} (h−1)·|q_k|·max_{j unassigned in class(k)} |q_j|.
    Prune when the implied CSM is ≥ the incumbent (the k-th best when `multi` = k).
  - **Ordering**: visit atoms by decreasing |q_k|. At each node try the fixed-point option and
    candidate cycles best-first, by standalone contribution.
  - **Incumbent**: start from the best of the identity permutation and a quick greedy pass. After
    Phase 6, start from the approximate solution.
  - Count visited nodes into the result's statistics.
- `OPEN` **P2.3** `--perm` support: a user permutation (1-based), validated
  (`InvalidPermutation`), orientation-only solve. cosymlib allows this only for Cs/Ci/C1; here it
  works for every group because validity is checked.
- `OPEN` **P2.4** Tests:
  - **Zero measures** with tolerance 1e-4 (the shapes in `data/standard_shapes.rs` carry finite
    precision):
    - `ideal_benzene.xyz`: C2, C3, C6, S6, Ci, Cs = 0.
    - `ideal_water.xyz`: C2, Cs = 0.
    - Built-in OC-6 vertices: C2, C3, C4, S4, S6, Ci, Cs = 0.
    - T-4: C2, C3, S4, Cs = 0 and Ci > 0.
    - TPR-6: C2, C3, S3, Cs = 0 and Ci > 0.
    - IC-12: C5, S10, Ci = 0.
  - **Invariance**: random rotation, translation, uniform scaling and reordering of atoms within a
    label class leave the CSM unchanged (1e-9). A random-number dependency is not needed:
    use fixed matrices or a tiny deterministic generator in tests.
  - **Monotonicity**: CSM(C2) ≤ CSM(C4) ≤ CSM(C8), CSM(C3) ≤ CSM(C6), CSM(Ci) ≤ CSM(S6),
    CSM(C2) ≤ CSM(S4) on random structures.
  - **Self-consistency**: the reported CSM equals 100·Σ|q−p̂|²/A from the reported P and axis.
  - **Exactness**: on structures with ≤ 7 atoms, branch-and-bound equals brute force over all
    valid permutations.
  - **Parity**: P0.1 and P0.2 fixtures, using the §3 parity policy.
  - **Search size**: assert node counts (not time) on La03 for C3, so pruning regressions show up.

**Acceptance:** all tests green; parity table in the PR description; no change to other
subcommands' output.

### Phase 4 — Continuous chirality measure

- `OPEN` **P4.1** `chirality.rs`: CCM = min over improper groups. By monotonicity (§2.4), only
  **Cs, Ci, S4, S8, S12, …** (S_{4m}) need computing: S_{4m+2} ⊃ Ci and S_odd ⊃ Cs, so they can
  never be smaller. `--order N` caps the largest S_n considered (cosymlib caps at 8). Report which
  group attained the minimum, plus its axis and permutation. Note: cosymlib computes S6 and
  computes Ci only when order ≥ 2; we skip S6 by the subgroup argument. Document this.
- `OPEN` **P4.2** CLI `DECIDE` D-A: a `ccm` subcommand (recommended) or `csm --chirality`.
- `OPEN` **P4.3** Tests:
  - Achiral fixtures give CCM ≈ 0 (water, benzene, OC-6, T-4).
  - A chiral twisted structure (e.g. a Δ-twisted trigonal prism) gives CCM > 0, unchanged under
    mirroring: the CCM of the mirror image equals the CCM of the original.
  - Update `PLAN.md` item 10.

### Phase 5 — Connectivity-preserving permutations (optional flag)

- `OPEN` **P5.1** Bond graph: atoms i and j are bonded if d_ij < factor·(r_i + r_j) with
  `covalent_radius`. `DECIDE` D-D: default factor. Recommended 1.2 (cosymlib's default; symgroup's
  stand-alone default is 1.1; cosmochlore's mol2 writer uses 1.3). The flag is off by default.
- `OPEN` **P5.2** Refine label classes by 1-WL colour refinement (element, then the multiset of
  neighbour colours, iterated to stability). This is sound because automorphisms preserve WL
  colours, and it replaces D8.
- `OPEN` **P5.3** In `search.rs`, when a cycle closes, check bonded(i, j) = bonded(P(i), P(j)) for
  every pair involving the new atoms; prune on violation.
- `OPEN` **P5.4** Tests:
  - Graph-automorphism enumeration matches a brute-force check on small molecules.
  - Turning connectivity on never lowers the CSM, because it only restricts P.
  - Document that bonds near the cutoff can make a distorted structure's true symmetry
    unreachable.

### Phase 6 — Approximate algorithm for large structures

- `OPEN` **P6.1** `approx.rs`: alternating optimisation.
  1. **Seeds**: the 3 principal axes of Σ q qᵀ, plus `fibonacci_hemisphere(n)` directions.
  2. For each seed v, repeat until P is unchanged or the overlap gain is < tol:
     - **(a) Permutation step.** For each label class, run Hungarian with cost
       C[k][j] = −q_k·g_1(v) q_j, i.e. pair atom j with atom k when g carries q_j onto q_k.
       Keep the centre pinned.
     - **(b) Repair.** Keep the cycles whose length divides h. Re-run Hungarian on the remaining
       atoms (up to r rounds). Atoms still left over become fixed points. The result is always
       valid.
     - **(c)** Exact orientation for that P (P1.2).
     - **(d)** Accept only non-decreasing overlap. If a permutation step lowers it, keep the
       previous P.
  3. Keep the best result over seeds. Mark the result `exact = false`.
- `OPEN` **P6.2** Mode selection:
  - Auto = exact when the candidate count (§2.4) ≤ `exact_limit` (`DECIDE` D-E; start at 10⁷,
    tune with node-count data), otherwise approx.
  - `--exact` forces exact (`SearchTooLarge` above a hard cap); `--approx` forces approx.
  - The approximate result is always used as the initial incumbent of the exact search.
- `OPEN` **P6.3** Tests:
  - Approx ≥ exact on every small fixture, and equal on the symmetric ones.
  - Exact search with the approx incumbent visits ≤ the nodes it visits without one.
- `OPEN` **P6.4** (optional) `rayon` parallelism over top-level branches, seeds and groups
  (`PLAN.md` C8).

### Phase 7 — Multi-generator point groups (research; design review before coding)

Goal: CSM for C_nv, C_nh, D_n, D_nh, D_nd, T, T_d, T_h, O, O_h, I, I_h, using the 47 tables in
`data/pgs.rs`. Sketch only; an agent must first write a short design note in this section and get
it approved.

- `OPEN` **P7.1** Group machinery:
  - Add the identity.
  - Build the multiplication table by matching matrix products against the table (tolerance 1e-9).
  - Find a small generating set automatically: greedily take an element of maximal order, then
    add elements outside the generated subgroup until closure.
- `OPEN` **P7.2** Homomorphism enumeration φ: G → S_N.
  - Assign permutations to the generators, each satisfying P^{ord} = id plus label and centre
    constraints.
  - Close under products by BFS. If the same group element is reached with two different
    permutations, reject.
  - The general measure is
    CSM = 100(1 − (1/(|G|·A)) max_{R,φ} Σ_{g∈G} Σ_k q_k · (R g Rᵀ) q_{φ(g)(k)}).
- `OPEN` **P7.3** Orientation over SO(3) (no closed form):
  - Seeds from `seed_rotation_vectors`, which already handles in-plane periods.
  - Refine by Nelder–Mead (argmin, already a dependency) or Riemannian gradient ascent. The
    gradient is analytic, since the objective is Σ_g tr(g Rᵀ X_g R) with
    X_g = Σ_k q_{φ(g)(k)} q_kᵀ.
  - For large N, alternate with Hungarian on the generators plus closure repair, as in Phase 6.
- `OPEN` **P7.4** Tests:
  - Every built-in shape in `data/standard_shapes.rs` scores ≈ 0 against its listed point group,
    when that group is in `pgs.rs`.
  - CSM(G) ≥ max over cyclic subgroups H of CSM(H).
  - The `csom` orientation may be used as a seed, but its *values* must not be compared with CSM.

## 6 · Pitfalls checklist

- Sign of b and direction of rotation: run the §2.3 sign test before anything else.
- Odd S_n has h = 2n. Ci = S2 and Cs = S1 must give identical results under both spellings.
- The central atom is a pinned fixed point **and** contributes to A and to the centroid.
- Clamp the CSM to [0, 100]; guard A ≈ 0.
- Deterministic output: label classes in a stable order (BTreeMap); stable tie-breaking between
  equal measures (lexicographically smallest permutation).
- Multi: deduplicate ±v; prune against the k-th best, not the best.
- Saturating arithmetic in candidate counting (factorials overflow u64 quickly).
- Do not reuse csom's "deviation" vocabulary or its CSV columns for csm.
- Line numbers in this file and in `PLAN.md` drift; grep.
